# 🧮 3D Calculator

A professional, colorful and responsive 3D Calculator application built with HTML, CSS and JavaScript.

## ✨ Features

- 🎨 Professional 3D glass-style design
- 🌈 Colorful modern interface
- 🧮 Basic mathematical calculations
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- ⌫ Delete and Clear buttons
- ⌨️ Keyboard support
- 📱 Mobile responsive design
- 🎯 Custom app icon
- ⚡ Fast and lightweight
